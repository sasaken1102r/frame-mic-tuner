# Changelog

## Unreleased

- Fix: the mic was sometimes far too loud, especially in the first seconds after you start speaking. SteamOS 20261015 added a second ("fallback") echo canceller that Valve's microphone tracker uses instead of the main one when the output isn't the Frame's speakers. This project's tracker turned on every filter whose name starts with `echo_cancel`, so both were in the chain and their automatic gain control was applied twice (measured on a Frame: about 5 dB more at the start of speech and roughly six times as many clipped samples). The tracker now follows Valve's choice: the main echo canceller with the Frame's speakers, the fallback one (with the current output as its echo reference) with any other output, never both. On SteamOS versions without the fallback, the main one is used for every output as before. Noise suppression still follows its switch for every output (Valve only uses it with the Frame's speakers), and no filters are turned on when the default mic isn't the Frame's built-in mic, as the panel says. Takes effect after restarting the headset.

## 0.3.3 (2026-10-25)

- Fix: noise suppression strength jumped back to SteamOS's default (23% / 500 ms) and that default was saved for the current output. With PipeWire 1.6 (seen on the current SteamOS beta), a value written to the noise suppressor before anything has used the mic since the headset started is kept by PipeWire and applied once the mic is used, but reading it back still shows the old value. The app took that old value for a change made in the panel. Now, when the value read right after writing is still the old one, the app shows and keeps the value it wrote, and goes back to what it reads once the reading changes (the mic is used, or the noise suppressor is set up again). If your saved strength was reset, set it once more after updating.

## 0.3.2 (2026-10-18)

- German, French, Spanish and Italian UI (thanks to @marcus-universe, #4). The language switch at the bottom left is now a menu with all seven languages: 日本語, English, 简体中文, Deutsch, Français, Español, Italiano. On first start the panel follows Steam's language (`german`, `french`, `spanish` or `latam`, `italian`), then the system locale; the settings file and `--language` take `"de"`, `"fr"`, `"es"`, `"it"`. The README is also available in these languages and in Simplified Chinese. Long labels in the new languages wrap to two lines or use shorter wording instead of being cut off. The update box and the list of the author's apps come from shared code that only has Japanese, English and Simplified Chinese, so they stay in English in the new languages. The language icon is from Heroicons (MIT, see `THIRD_PARTY_LICENSES.md`).
- Wider panel: 1400×788 instead of 1200×788 (close to 16:9), shown about 3.27 m wide in the dashboard so everything stays the same size (same pixels per meter as before). The extra width goes to both columns: the output picker, the presets and Fine-tune rows get more room, so most labels that were wrapped or shrunk in French, Spanish and Italian now fit on one line at the normal size, and the voice check history shows more of each recording's settings. The pickers, the app list and the dialogs use the new width too; buttons whose label doesn't fit in some languages (Default, Open in Konsole, the installer button, the picker buttons) grow instead of shrinking the text.

## 0.3.1 (2026-10-17)

- Smaller and a little faster (thanks to @cinnacappu, #3): Release builds use link-time optimization when supported and drop unused code and data (the stripped executable is about 20% smaller), and the panel's Cairo-to-RGBA conversion skips the lookup table for fully opaque or fully transparent pixels (about half the time for an opaque panel on a Frame). The picture is unchanged. `ctest` runs `--self-test` and a new pixel-conversion test (`tests/rgba_test.cpp`); tests are not built for release packages.
- Japanese UI: the heading of the author's app list now reads 「ささけん＠の Frame アプリ」 (full-width ＠), matching the author's name elsewhere. frame-apps 0.3.2.
- Log: while you drag a Fine-tune slider, the log now says the current output's settings were "changed in the panel" instead of "changed from outside".

## 0.3.0 (2026-10-10)

- Simplified Chinese UI (thanks to @boholder and @dhies23, #1). The language switch at the bottom left is now **日本語 / English / 简体中文**. The panel starts in Simplified Chinese when Steam is set to Simplified Chinese (`schinese`; without a Steam setting, a `zh_CN` locale); the settings file and `--language` take `"sc"`.
- Mute: the panel notices when the default mic is muted, however it was muted (Steam, `wpctl set-mute`, an aux button shortcut, ...), by reading `wpctl get-volume @DEFAULT_AUDIO_SOURCE@` with the rest of the state. The header shows a red "Muted" with a crossed-out mic, and a **Mute** / **Unmute** button next to it (`wpctl set-mute @DEFAULT_AUDIO_SOURCE@ 1` / `0`, read back; no confirmation). The status and the button have fixed widths, so the button doesn't move when you mute. If muting or unmuting fails, the bottom line says so.
- Settings for each output: the Frame mic settings (echo cancellation, noise suppression and its strength) are remembered separately for each audio output (the Frame's speakers, USB-C earphones or adapters, Bluetooth headphones), keyed by the device's PipeWire node name (Valve's `alsa_loopback_device.*` wrapper maps to the speaker device itself; a Bluetooth device keeps one key across profiles). The app watches the default output every 2 seconds, also while the panel is closed (`pw-metadata -n default`, about 10 ms), and when it changes it applies that output's settings with the usual `wpctl settings --save` / `pw-cli set-param`, and the Quick tab says "<output> connected, so its saved settings are on" with **Undo**. It also applies them at startup. A new output starts from the Frame speakers preset if it's the Frame's speakers and from the Earphones preset otherwise; on the first start of this version, the current settings become the current output's. Changes made elsewhere (another tool, an aux button, `wpctl settings`) are remembered for the current output. Filter or virtual outputs are ignored.
- **Output** and **Mic** buttons above the settings: "Choose the output" lists the connected outputs and the ones used before, with **Play sound here** (`wpctl set-default`, the same setting as SteamVR's audio settings; Valve's wrapper node for the Frame's speakers), viewing and changing another output's settings ahead of time, and **Forget**. The list scrolls with the controller stick (`VROverlayFlags_SendVRSmoothScrollEvents`) or by dragging. "Mic to use" switches the default mic; with a mic other than the Frame's built-in one, the settings card explains that echo cancellation and noise suppression don't apply and offers **Use the built-in mic**.
- New look, matching the other Frame panels (shared `vendor/frame-ui/`): the settings card shows "When listening on <output>" with the two presets; the voice check history says which output (or external mic) each recording was made with; the bottom row has three languages and a new note line.
- **Apps & updates** (top right, with a pink dot when there's a new version or the companion app is missing): this app's version and the update check / **Update** (moved here from the full-width update card, which is gone), a **Check for updates** on/off switch (the `update_check` setting), the companion app frame-aux-shortcuts (toggles the mic mute with the aux button), and the list of the author's other Steam Frame apps (shared `vendor/frame-apps/`). With **Check for updates** on, the list and icons are fetched from frame.sasaken1102s.net at most once an hour. **Install** shows the exact installer command first and then opens it in Konsole.
- The Fine-tune sliders no longer have − / ＋ buttons (drag the slider).
- `--print` lists the outputs and mics with their keys and the node used for `set-default`, the defaults, and the saved settings for each output (read only). `--dump-png` has new `--view`, `--overlay`, `--fake-output`, `--fake-past-outputs`, `--fake-switched`, `--fake-external-mic`, `--fake-viewing`, `--preview-scroll`, `--fake-aux`, `--fake-apps-busy`, `--fake-apps-extra`, `--fake-confirm` and `--fake-launch` options; `--self-test` checks the output parsing with output captured on a Frame.

## 0.2.0 (2026-09-27)

First release with a prebuilt package (`frame-mic-tuner-<version>.tar.gz` + `SHA256SUMS`, built by `scripts/package.sh`); `install.sh` now installs either from that tarball or, as before, by building from a source checkout.

- Updates: an update card above the language/autostart/quit row always shows the running version. It asks GitHub for a newer release about once a day (`update_check` setting, on by default), and **Check now** looks right away regardless, even with automatic checking off. When a newer version is available, **Update** downloads and installs it after you confirm once (the card asks again with **Cancel** / **Update**; checksum-verified against the release's `SHA256SUMS`; nothing changes if that check fails). Shared with the other Frame apps via `vendor/frame-updater/`.
- The update card shows its state at a glance: an accent-colored border for a new version, the confirmation and a finished install, a red border with **Try again** / **Close** when an update failed, and red text (with **Check now**) when only the check failed.
- `install.sh` now writes `~/.config/frame-mic-tuner/install-args` with the options your last install used (currently just `--autostart`, when passed), so an update started from the panel reinstalls the same way.

## 0.1.0 (2026-09-27)

First release.

- A "Mic" panel in the SteamVR dashboard that switches the Steam Frame's microphone filters, with two tabs ("Quick" and "Fine-tune"; it reopens on the last one): presets for how you listen ("Earphones / headphones" = echo cancellation off and noise suppression off, "Frame speakers" = echo cancellation on and noise suppression off; each card shows what it sets, and both cards turn grey when the settings match neither), plus separate "Fine-tune" switches for echo cancellation and noise suppression. Changes apply at once, even while the mic is in use, and are kept after a restart.
- Noise filter strength sliders (Strictness = VAD threshold, Hold = VAD grace period) that apply live without restarting PipeWire. The values are saved and applied again whenever the app starts.
- Shows whether the mic is in use and which filters the sound actually goes through, read from the live PipeWire links.
- Voice check: record up to 10 seconds of what apps hear, keep the last 5 recordings in memory and play them back to compare settings. Nothing is written to disk.
- Japanese and English UI. It starts in the Steam Frame's language (from Steam's language setting) and remembers your choice. Colors meet WCAG 2.x AA contrast (`--contrast-report` prints every pair).
- Self-repair: if SteamVR loses the app's dashboard panel (for example when the dashboard restarts), the app notices within 3 seconds and recreates it.
- Starts from the dashboard's "+" (launch a program) list. Launching it again while it runs opens its panel. Optional autostart with SteamVR, switched from the panel.
- Includes the WirePlumber script (`contrib/wireplumber/`) that makes the filters switchable without restarting PipeWire.
- `install.sh` builds and installs everything into the home directory, with no sudo and no PipeWire / WirePlumber restart.
